#  Cartas Alicerçadas

Website desenvolvido para apresentar o grupo de jovens **Cartas Alicerçadas**, reunindo informações sobre o ministério, localização, integrantes e eventos como o acampamento anual.

Além da apresentação institucional, o projeto foi desenvolvido como prática inicial de desenvolvimento front-end, com foco em estruturação de páginas utilizando **HTML, CSS e Flexbox**.

---

## Sobre o projeto

Este projeto surgiu como um desafio proposto pela liderança do grupo de jovens, com o objetivo de criar um site simples que apresentasse o ministério para novos visitantes.

A proposta foi desenvolver uma página informativa contendo seções sobre:

- Quem somos
- Localização
- Ministério
- Acampamento

Durante o desenvolvimento, o foco principal foi aplicar conceitos fundamentais de **estruturação de layout e responsividade** utilizando tecnologias básicas do front-end.
